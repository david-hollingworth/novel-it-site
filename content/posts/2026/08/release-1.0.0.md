It's been some time coming, but I'm delighted to announce the release of Novel-It version 1.0.0.

Since the first phase 1 test run many bugs have been fixed, the card layout has been standardised across the application. World Building has been introduced (it was always supposed to be part of phase 1, but was omitted from the first test run). Most recently I've changed from a manual to a fully automated test suite, which saves me a huge amount of time. Plus it unearthed a number of bugs that I was able to fix before the release.

So what's next? Phase 2 includes rounding out some of the phase 1 functionality, for example you cannot archive or delete the planning entities at the moment. Those missing requirements will be satisfied. But the big feature for phase 2 is the plotting module and its integration with the writing module. This is in the initial design phase, so more on that in the autumn.

I hope you enjoy using Novel-It as much as I have creating it. Back to the writing now, wht's it going to be? COde or prose.....
